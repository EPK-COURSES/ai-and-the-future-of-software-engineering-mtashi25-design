# Reference Sources Used in This Research

To analyze the impact of AI on software engineering, this paper pulled data and insights from five key industry reports published by major tech platforms and consulting firms:

1. **GitHub Engineering Reports (2024)**  
   *The State of the Octoverse: AI adoption and developer velocity trends.*  
   This report provided the statistical baseline showing that developers complete coding tasks roughly 55% faster when using AI assistants, and detailed how AI is changing language trends like the rise of Python.  
   Available at: https://github.blog/industry-insights/

2. **McKinsey Global Institute Research (2023)**  
   *The economic potential of generative AI: The next productivity frontier.*  
   This study contributed the broader economic and productivity metrics, specifically highlighting that generative AI cuts documentation time in half and speeds up everyday coding tasks by 35% to 45%.  
   Available at: https://www.mckinsey.com/capabilities/mckinsey-digital/our-insights/

3. **Stack Overflow Insights (2024)**  
   *Developer Survey Results: AI tools, adoption rates, and developer trust metrics.*  
   This source provided the critical data tracking developer sentiment, revealing the massive paradigm gap where over 75% of developers use AI tools, but only about 40% actually trust the outputs.  
   Available at: https://survey.stackoverflow.co/

4. **Deloitte Development LLC (2024)**  
   *State of Generative AI in the Enterprise: Accelerating software lifecycles and addressing risk.*  
   This enterprise report backed up the findings on developer velocity, showing how companies investing in generative AI are seeing significant speed improvements across the entire software delivery timeline.

5. **GitLab Survey Insights (2024)**  
   *Global DevSecOps Report: The shifting bottleneck from code generation to security testing.*  
   This report was crucial for the risk assessment section, proving that rapid AI code generation has shifted the main development bottleneck downstream into security verification and code quality audits.
